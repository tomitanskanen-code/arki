# iPhone-testauksen tarkistuslista

Kokeilkaa nämä kotinäytön Arki-kuvakkeesta (ei Safarin välilehdeltä).
Merkitse ongelmat ja kerro ne kehityskeskustelussa.

## Perusasiat

- [ ] Sovellus avautuu ilman Safarin osoiteriviä.
- [ ] Ylä- ja alareuna eivät jää kellon, loven tai kotipalkin alle.
- [ ] Kirjautuminen säilyy, kun sovellus suljetaan ja avataan uudelleen.
- [ ] Alanavigaation kaikki neljä kohtaa toimivat ja ovat helppoja painaa.

## Tänään

- [ ] Päivämäärä ja sää ovat oikein (kotipaikkakunta Porvoo).
- [ ] Hugon koulupäivä näkyy Lapset-osiossa oikeaan aikaan; napautus avaa
      oppitunnit.
- [ ] Harrastukset (myClub) näkyvät oikealla lapsella.
- [ ] Perheen Google-kalenterin menot näkyvät Menot-osiossa.
- [ ] "Kouluruokalista" avaa Porvoon ruokalistan.
- [ ] Kun sovellus on ollut taustalla yön yli, aamulla näkyy uusi päivä.

## Kalenteri

- [ ] Päivä- ja viikkonäkymä vaihtuvat; pyyhkäisy vaihtaa päivää/viikkoa.
- [ ] Jäsensuodatin (Hugo, Noel …) toimii.
- [ ] Tapahtuman lisätiedoissa näkyvät aika, paikka ja lähde.
- [ ] Kesä- ja talviajan vaihteen viikolla ajat ovat oikein.

## Kauppalista

- [ ] Tuotteen lisäys, ostetuksi merkintä, palautus ja poisto toimivat.
- [ ] Toisen vanhemman lisäämä tuote ilmestyy ilman päivitystä.
- [ ] Toimii myös, kun sovellus on välillä ollut taustalla.

## Tumma tila

- [ ] Asetukset → Näyttö ja kirkkaus → Tumma: Arki vaihtuu tummaksi.
- [ ] Tekstit ovat luettavia, ja väripisteet erottuvat.

## Saavutettavuus (valinnainen)

- [ ] Suurempi tekstikoko (Asetukset → Näyttö → Tekstin koko) ei riko
      näkymiä.
- [ ] VoiceOver lukee painikkeet järkevästi (esim. "Poista Maito").
